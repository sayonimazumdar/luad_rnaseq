# Lung adenocarcinoma tumor vs. normal RNA-seq (3 paired patients)

A small, laptop-sized RNA-seq project: transcript quantification of matched lung adenocarcinoma (LUAD) tumor and
adjacent normal tissue, followed by paired differential expression analysis.

## Biological question
Which genes and pathways differ between lung adenocarcinoma (LUAD) tumor and adjacent normal lung tissue **from the same
patient**, and can a lightweight, reproducible pipeline recover the known biology from public data?
Pairing each tumor with its own normal removes most between-patient variation (DESeq2 design `~ patient + condition`).

## Data
- **Dataset:** GEO [GSE37764](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE37764) (BioProject PRJNA163279, SRA study SRP012656)
- Primary lung adenocarcinoma and adjacent normal tissue from never-smoker Korean female patients (Kim et al., PLoS ONE 2013)
- **Used here:** RNA-seq from patients **P1, P3, P4** (3 pairs = 6 samples; each sample was sequenced in 2 runs = 12 SRR runs, see `metadata/samples.csv`)
- To keep the project small, only the first **6 million reads per sample** (3M per run) are used

## Pipeline
| Step | Script | What it does |
|---|---|---|
| 0 | `scripts/00_setup.sh` | Creates the conda env, downloads GENCODE v47, builds the Salmon index |
| 1 | `scripts/01_fqdump_quant.sh` | Per sample: `fastq-dump -X` (first reads only) -> `fastp` trimming/QC -> one `salmon quant` for both runs of the sample -> deletes reads |
| 2 | `scripts/02_multiqc_tx2gene.sh` | MultiQC report, Salmon mapping rates, transcript-to-gene table for tximport |
| - | `scripts/03_make_samples.py` | (Optional) rebuilds `metadata/samples.csv` from NCBI's run table |
| 4 | `scripts/04_deseq2.R` | tximport -> DESeq2 (`~ patient + condition`), PCA, MA/volcano plots, top-50 heatmap, DE tables in `results/` |
| 5 | `scripts/05_enrichment.R` | GO and KEGG over-representation (up/down genes) and Hallmark GSEA with clusterProfiler |
| 6 | `scripts/06_export_matrices.R` | Exports gene x sample raw-count and TPM matrices (the "feature matrix") |

## Key results
- Salmon mapping rates 85.2 to 92.1% (mean 89.1%); 17,521 genes tested.
- 666 genes up and 1,007 down in tumor (adjusted p < 0.05, |shrunken log2FC| > 1).
- Down in tumor: alveolar/endothelial genes (*AGER*, *CLDN5*, *CAV1*, *CLDN18*); angiogenesis and vasculature GO terms.
- Up in tumor: *CEACAM5/6*, *AGR2*, mucins, *TOP2A*; GO immunoglobulin-mediated immune response; Hallmark E2F targets (NES +2.48) and glycolysis (NES +2.15).
- The top genes changed in the same direction in all three patients.
- Full write-up: [`docs/LUAD_RNAseq_Report.docx`](docs/LUAD_RNAseq_Report.docx). Figures are in `results/figures/` and `results/enrichment/`.

## Repository layout
```
scripts/     numbered pipeline steps (bash, python, R)
metadata/    samples.csv  (SRR run -> patient / condition)
results/     DE tables, matrices, figures, enrichment output
docs/        project report
environment.yml, environment-r.yml   conda environments
```

## How to run
```bash
git clone <this repo> && cd <repo>
bash scripts/00_setup.sh                # once: env, reference, Salmon index
conda activate luad-rnaseq

# long step (many hours); keeps running if the terminal closes, and resumes if restarted
nohup systemd-inhibit --what=sleep bash scripts/01_fqdump_quant.sh > logs/run_all.log 2>&1 &
tail -f logs/run_all.log

bash scripts/02_multiqc_tx2gene.sh

# differential expression and enrichment (separate R environment)
conda env create -f environment-r.yml
conda activate luad-r
Rscript scripts/04_deseq2.R
Rscript scripts/05_enrichment.R
Rscript scripts/06_export_matrices.R
```
Run everything from the project root; the scripts use relative paths. Finished samples (`quants/<sample>/quant.sf`)
are skipped on re-runs.

## Notes and limitations
- Only 3 patient pairs and a subsample of reads, so results are **exploratory**, not definitive.
- Raw data, the reference and Salmon outputs are not committed (see `.gitignore`); they are regenerated by the scripts.
- Quantification times depend on network speed (roughly 1.5 to 2 hours per sample in testing).

## Requirements
Linux, conda (or mamba), about 10 GB free disk. Command-line tools are in `environment.yml`; R packages are in `environment-r.yml`.
If `05_enrichment.R` asks for the `msigdbdf` package (newer msigdbr versions), install it from the R-universe as the error message shows.
